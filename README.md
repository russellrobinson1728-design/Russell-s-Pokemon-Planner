# Russ's Pokémon League OS — V20

A Unova-focused personal progression RPG with a late-2000s/DS-era pixel terminal aesthetic inspired by Pokémon Black/White 2.

## Included
- Responsive desktop and phone layouts
- Russ and DJ personalized trainer artwork
- Default male/female friend sprites from the supplied sprite sheet
- Six-Pokémon friend teams generated from exactly three adjectives
- Evolution stages scale with each trainer
- DJ and any friend can be selected as the active rival
- Pre-enabled self-growth quests plus custom quests
- Badge progress and coat of arms
- Journal, rewards and monthly tracker
- Live monthly countdown
- Working calculator with keyboard support and history
- Local save plus optional Supabase sync

Keep `assets/` beside `index.html` when uploading to GitHub Pages.
